# 嫂子模拟器 · 秘密练习簿

**[点这里开始玩](https://lovebirb10.github.io/secret-star-game/)** · [反馈问题](https://github.com/lovebirb10/secret-star-game/issues)

把恋爱藏进手机里：发微光、赴约、回短信。五天之后，你会把自己留在哪个结局？

这是一个像翻看私人手机一样的互动故事。五个结局、每天三位联系人的短信，还有可以随时关闭的验证小游戏。手机和电脑都能玩，不需要登录。

## 放到手机桌面

- **iPhone / iPad**：用 Safari 打开游戏 → 分享 → 添加到主屏幕；如果有“作为网页 App 打开”，请开启。
- **安卓**：用 Chrome 或支持安装网页应用的浏览器打开 → 菜单 → 安装应用／添加到主屏幕。
- 如果是在聊天软件里打开，先选择“在浏览器打开”。从桌面图标进入，会更接近独立小游戏。

第一次请联网打开并等待资源加载完成，之后可以离线玩。新版本需要联网获取；若还看到旧版本，关闭所有游戏窗口后重新打开。

## 存档与反馈

进度自动保存在当前浏览器／网页应用里，不会上传。浏览器与桌面应用的存档可能不互通；换设备、清除网站数据或卸载网页应用后，进度可能丢失。

遇到卡住、按钮没反应或文案问题，欢迎到 Issues 留言。带上手机型号、浏览器、游戏第几天和刚刚点了什么，会更容易定位。请不要贴私人聊天或个人信息。

角色均为虚构成年人，与真人无关。故事含网络骚扰与情感冲突描写。
